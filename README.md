# VidGrab — تطبيق تحميل فيديو بدون سيرفر

## التشغيل
1. افتح Android Studio (Koala أو أحدث) ← Open ← اختر مجلد VidGrab.
2. انتظر Gradle Sync (محتاج إنترنت أول مرة).
3. وصّل موبايل أو شغّل Emulator (Android 10+) ← Run ▶.
4. لعمل APK: Build ← Build APK(s).

## الاستخدام
- اكتب رابط أو كلمة بحث في الشريط، أو شارك رابط من أي تطبيق لـ VidGrab.
- شغّل الفيديو داخل الصفحة، هيظهر زر «تحميل (عدد)» ← اضغطه ← اختر الفيديو ← اختر الجودة.
- التحميلات من أيقونة التنزيل أعلى اليمين (إيقاف/استكمال/تشغيل/حذف).
- الملفات بتتحفظ في Movies/VidGrab (أو Music/VidGrab للصوت) وبتظهر في المعرض.

## بيدعم
- ملفات مباشرة: mp4, webm, mkv, mov, flv, avi, 3gp, mp3, m4a, aac, ogg, wav (مع إيقاف/استكمال).
- HLS (m3u8) مع اختيار الجودة، وفك تشفير AES-128، وfMP4.

## مش بيدعم
- المحتوى المحمي بـ DRM (Netflix وأمثاله) وSAMPLE-AES.
- DASH (.mpd) وفيديوهات blob: اللي بتتبني بـ MSE.
- مواقع بتغيّر الحماية أو بتطلب تسجيل دخول خاص ممكن تفشل.
- HLS اللي الصوت فيه ملف منفصل هيتحمّل فيديو بدون صوت.
- استخدمه لمحتوى مسموح لك تحمّله.
